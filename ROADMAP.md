# Roadmap

Este documento presenta las funcionalidades planeadas para futuras versiones del Sistema de Gestión de Inventario para Mini Súper.



## Versión 1.1

- Gestión de clientes.
- Búsqueda avanzada de productos.
- Alertas de inventario bajo.



## Versión 1.2

- Reportes gráficos de ventas.
- Exportación de reportes a PDF.
- Exportación a Excel.



## Versión 1.3

- Gestión de usuarios mediante roles.
- Bitácora de actividades.
- Historial de movimientos del inventario.



## Versión 2.0

- Integración con lectores de código de barras.
- Respaldo automático de la base de datos.
- Implementación en la nube.
- Panel de indicadores (Dashboard).
- Aplicación móvil para consulta del inventario.
